# 2026-08-02 — v0.5a.1 接入中心（一键注册 cockpit MCP，不用手改 JSON）

## 状态
**现行版本**（v0.5a.1，立）

## 背景

v0.5a 把 cockpit MCP server 做出来了（5 个工具 + stdio + 7 e2e 测试），但**用户接入的摩擦在最后一步**：要手改 `~/.claude/mcp.json`、Cline 那条长得离谱的 VSCode 路径、Trae 还不让全局只能项目级。

用户原话：**"配置只能通过修改配置json来实现吗？没有更好的办法吗？比如让用户直接在Agent中选择"**。

核心洞察：**"一键"不是省代码，是省用户路径**。把"找文档 → 找路径 → 编辑 JSON → 验证" 4 步砍成"点 1 个按钮"。

## 决策

### 1. 后端路由 4 个端点

| 端点 | 用途 |
|---|---|
| `GET /api/integrations/supported` | 列出 6 个 agent + 当前 OS + 各 agent 配置路径 + 接入状态 |
| `POST /api/integrations/install` | 写 cockpit 段到目标 config |
| `POST /api/integrations/uninstall` | 删 cockpit 段（其他 server 保留）|
| `GET /api/integrations/status` | 快速查 cockpit 在哪些 agent 已接入 |

### 2. 6 个 agent 两种 type

| Agent | Type | Scope | 备注 |
|---|---|---|---|
| Claude Code | json | user | 全局 `~/.claude/mcp.json` |
| Cursor | json | user | 全局 `~/.cursor/mcp.json` |
| Trae | json | **project** | Trae 不支持 user-level，只能在 cockpit 项目根目录写 `.trae/mcp.json` |
| Cline (VSCode) | json | user | 路径长到手改必出错，正好是一键的价值 |
| Continue | json | user | `~/.continue/config.json` |
| WorkBuddy | **command** | — | 不写 JSON，走对话命令 `workbuddy mcp install cockpit` |

**type=json**: 后端读现有 config → 只改 `mcpServers.cockpit` 段 → 写回（临时文件 + rename 防半写）。
**type=command**: 不写 config，返 `install_command` 字段，前端做"复制"按钮（用户到 WorkBuddy 对话框粘贴）。

### 3. 关键不变量 — 不破坏现有 config

- 读 JSON → 修改 `mcpServers.cockpit` 段 → 其他 server 一律不动
- 写文件用 **临时文件 + os.replace**（`mkstemp` + `replace`），不在原文件上覆盖写。断电 / 进程被杀 都不会留半截 JSON
- 如果 config 不存在 → 当空对象处理，新建
- 如果 config 解析失败 → 警告日志 + 当空对象处理（不阻塞用户）
- 卸载时如果 `mcpServers` 为空 → 整段删掉，不留 `{"mcpServers": {}}`

### 4. 跨平台路径

`_expand(path)` 一层 `os.path.expanduser` + `os.path.expandvars`，所以 `%USERPROFILE%` (Windows) 和 `~` (Unix) 都自动展开。

`_detect_cockpit_path()` 优先用 `COCKPIT_INSTALL_PATH` 环境变量，兜底用 `os.getcwd()`。这样部署到 docker / 不同机器都能装对。

### 5. 前端 `/integrations` 页面

跟 v0.4.x 输出端一致的设计语言：
- 6 张卡片，2 列网格
- 每张卡片：名字 + scope badge（user/project）+ status badge（已接入/未接入/待手动）+ 描述 + 当前 OS 路径（json 类型）+ 操作按钮
- **底部总览条**：已接入 N/6 + 设计说明
- 5 个 json 类型 agent → 一键安装/卸载按钮（带 loading）
- WorkBuddy (command) → "复制安装命令" + "详细"（复制 manual_command 含完整步骤）
- post_install 提示 + docs 外链
- 复制反馈：1.5s 复位移除

### 6. nav 入口

主页 MainBoard 顶栏加 `🔌 集成` 链接，跟 `写周报` / `PR 描述` / `CV 视图` 同级。

| 项 | 结果 |
|---|---|
| 新测试 | ✅ **17 passed, 0 failed** |
| 完整套件（后端） | ✅ **340 passed, 1 skipped**（323 → 340，+17 新测试）|
| tsc --noEmit | ✅ 0 错 |

**17 个测试覆盖**：
- supported 返 6 个 agent + 各自 type 字段
- status 空环境 installed_count=0
- install 写 cockpit 段正确 (command/args/cwd)
- install 保留其他 server (other_server + another 都在)
- install 走默认 cockpit_path (cwd 兜底)
- install 幂等 (was_already_installed=True 重装)
- install 拒绝 command 类型 (WorkBuddy 应走对话命令)
- install 未知 agent_id → 404
- uninstall 删 cockpit 段 + 保留其他 server
- uninstall 清空 mcpServers 整段 (不留空对象)
- uninstall config 不存在 graceful
- uninstall cockpit 不在 config 中 graceful
- uninstall 拒绝 command 类型
- 端到端: install → status 变化 → supported.is_installed 变化 → uninstall → 回到 0
