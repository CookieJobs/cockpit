# 2026-08-02 — v0.4.6 今日已完成区移位 (跟 spotlight 卡片联动)

## 状态
**现行版本**（v0.4.6，立）

## 背景

v0.4.4 立的"本期成就 spotlight 卡片" 副 stack 已经有 "今日 +N" 指示器,
但 DoneTodaySection 还在 ProjectsSection + DoneAllSection 之后 — 用户得
滚到底才能看到今天干了啥。

## 决策

**DoneTodaySection 移到 spotlight 卡片正下方, FocusSection 之前**:
- 之前顺序: spotlight → FocusSection → ProjectsSection → DoneAllSection → DoneTodaySection
- 现在顺序: spotlight → DoneTodaySection (今日已完成, 折叠展开) → FocusSection → ProjectsSection → DoneAllSection
- 视觉效果: 主页第一屏能直接看到"今天已经干了啥", 跟 spotlight 卡片副 stack 里的"今日 +N" 联动
- 跟 lesson #14 / #22 同源: "今天我干的活不见了" 修复 — 已沉淀的成就不藏, 直接给用户看
- 跟 lesson #21 同源: 重复入口不保留 — spotlight 卡片副 stack 的 "今日 +N" 跟 DoneTodaySection 链接, 不再单独加 /today 路由
