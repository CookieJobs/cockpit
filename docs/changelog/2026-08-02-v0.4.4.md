# 2026-08-02 — v0.4.4 本期成就卡片 (5 秒 Wow 时刻强化)

## 状态
**现行版本**（v0.4.4，立）

## 背景

v0.4.3 修完主题 bug 后, 进入"投资人 ↔ 技术负责人"循环 Round 1。投资人视角
挑刺 6 条, 排序后聚焦 #1 (5 秒 Wow 时刻) + #2 (价值闭环) — 都是同一改动
能解决的。

### 投资人挑刺摘要

| # | 挑刺 | 选不选 |
|---|---|---|
| 1 | 主页跟 Trello/Todoist 长得 90% 一样, 5 秒抓不到差异化 | **改** |
| 2 | 沉淀 → 履历 → 输出 闭环不在主流程自然发生 | **改** |
| 3 | 目标用户混 (个人 vs 团队) | 暂不改 |
| 4 | AI 是 add-on 不是 differentiator | 暂不改 |
| 5 | 无护城河 | 暂不改 |
| 6 | 无变现 | 暂不改 |

#1 + #2 共因: 主页"待办焦虑"权重 > "已有积累"权重 — 进 cockpit 第一眼
看到的是"我还有 5 项没干", 不是"我已经沉淀 12 条成就"。心理重心该切。

## 决策

**把主页 counter 窄条升级为 "本期成就 spotlight 卡片"**:

- 大数字 `readyCount` (28px / bold / tabular-nums / 跟 "12 条成就" 文案对比明显)
- 副 stack: 今日 +N · 待补 N · 待办 N (一行 3 列, 11px fg-muted)
- 底部: "查看全部 12 条成就 →" link 链 /achievements (闭环)
- **highlight 动画**: readyCount +1 (任务完成 → 沉淀成就) 时
  - 卡片背景 flash `bg-accent/10` 1.5s
  - 数字颜色 `text-fg` → `text-accent` 1.5s transition
  - "12" 旁冒 "+1" 角标 `animate-pulse`
- **心理钩子**: "我刚做的事被记下来了, 数字看得见" — 完成 → 沉淀闭环可视化
- **不动结构**: 卡片在原 counter 位置 (border 之上), FocusSection 还在下面

设计决定 (跟 lesson #11/#13 同源, 不要视觉堆叠):
- 不加 bg gradient / glow / 装饰图标 — 简单 bg-tertiary 边框就够了
- 数字不加 counter-up 动画 — 1.5s 静态 highlight 足够, counter-up 在小数字 (12)
  看着像 CPU 风扇
- "+1" 角标用 animate-pulse (Tailwind 内置), 不自己写 keyframes
