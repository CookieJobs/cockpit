# 2026-08-02 — v0.5a.2 主页 nav 强化 "⚡ AI 直连" 入口

## 状态
**现行版本**（v0.5a.2，立）

## 背景

v0.5a.1 立了"接入中心" /integrations, 是个杀手功能: 让 Claude Code / Cursor /
Trae / Cline / Continue / WorkBuddy **6 个 AI Agent 直接读 cockpit 数据**
(项目 / 任务 / 成就)。这是**任何竞品 (Reflect / Mem / Notion) 都没有的能力**。

但 v0.5a.1 的入口只是主页 nav 第 5 个位置的小 Plug 图标 + "集成" 文字 —
杀手功能**完全埋没**。普通用户进 cockpit 根本不知道"我的 Claude Code 能
直接读 cockpit"。

## 决策

**主页 nav 升级 "集成" 链接 → "⚡ AI 直连"**:
- 文字 "集成" → "⚡ AI 直连" (强调价值, 不是技术)
- 颜色 `text-fg-secondary` → `text-accent` (跟其他 nav 区分, 视觉重量强)
- 加 **红点 dot**: 当 `installed_count < total_count` 时显示 (默认 6/0)
- 红点 `bg-danger animate-pulse` 1.5s 循环, 提醒"还没接入"
- hover tooltip 写明"装上能干啥": `把 cockpit 注册到 Claude Code / Cursor / Trae 等 6 个 AI Agent, 让它们直接读你的项目 + 任务 + 成就 (当前 0/6)`
- SWR 30s 轮询, 用户去 /integrations 装好后回主页, dot 自动消失

### 设计决定

1. **"⚡" emoji 选型**: ⚡ (闪电) 比 🤖 (机器人) / 🔌 (插头) 强 —
   - 🤖 太通用, 跟 chat 混了
   - 🔌 太技术, 没情绪
   - ⚡ 暗示"快速 + 强能力" + 视觉上比图标更醒目
   - 跟 lesson #11/#13 同源: 不要视觉堆叠, 但**强调关键功能**值得用 emoji

2. **"AI 直连" 文案选型**: 不说"MCP 接入" / "Agent 集成" / "连接" —
   - "AI 直连" = 你的 AI 工具能直读 cockpit (价值)
   - "MCP 接入" = 技术协议 (技术)
   - lesson #26 (Onboarding 减法) 同源: **新用户能秒懂 > 工程师能吹**

3. **红点 dot 而非文字 "未接入"**:
   - 红点占空间小, 不挤 nav
   - 红点是通用 "未读 / 提醒" 语言, 用户秒懂
   - 文字"未接入"会跟 nav 文字混一起, 视觉上啰嗦
   - lesson #21 (重复入口不保留) 同源: nav 文字 8 个, 不再加 1 个

4. **SWR 30s 轮询** (而不是 5min):
   - 6 个 Agent 装好需要 1-2 分钟, 用户期待"装了马上主页消失"
   - 30s 平衡"实时感" + "后端压力"
   - lesson #2 (CoT 暴露) 同源: 后端被调用的频率 vs 体验, 这里 30s 是甜蜜点
