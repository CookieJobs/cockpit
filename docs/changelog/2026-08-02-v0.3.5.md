# 2026-08-02 — v0.3.5 沉淀质量卡片（"沉淀质量" 视角首次进入 UI）

## 状态
**现行版本**（v0.3.5，立）

## 背景

v0.3.1 / v0.3.3 / v0.3.4 已经让"沉淀"这一段扎实了，但用户**看不见自己的沉淀质量**——积累 100 条成就，没人告诉他"70% 都没量化"、"50% 用弱动词"。

v0.3.5 立 "沉淀质量" 卡片，给用户"我做得怎么样"的反馈闭环。

## 决策

### 1. 3 个核心指标

| 指标 | 含义 | 怎么算 |
|---|---|---|
| **ready 比例** | 已就绪的成就占比 | `cv_status === "ready"` / total |
| **量化率** | cv 文本含具体数字/量级 | 正则匹配 `\d+(\s*(%\|万\|倍\|个\|人\|...))` 或"提升/增长+数字" |
| **强动词比例** | cv 以强动作动词开头 | 强动词清单（15 个，跟 POLISH_CV_SYSTEM 同步） |

### 2. 4 档评级

- ≥ 80% → 优秀 (success 绿)
- ≥ 60% → 良好 (accent 蓝)
- ≥ 40% → 一般 (warning 琥珀)
- < 40% → 待提升 (danger 红)

### 3. 不动后端，纯前端计算

- 数据从已有的 `/api/achievements` 拉一次
- 客户端 useMemo + 纯函数计算
- 不发新请求、不加端点
- **v0.4.3** 计划加 `/api/achievements/stats` 后端端点（让大数量不卡）

### 4. UI 设计：3 列网格 + 评级 chip

每个指标一个卡片，竖排：
- 顶部：label + 评级 chip
- 中部：大号百分比数字
- 底部：细节（"X / Y 条含量化"）
