# 2026-08-02 — v0.4.1 时间线 toggle（/achievements 加"按项目/按时间"切换）

## 状态
**现行版本**（v0.4.1，立）

## 背景

/achievements 现状是"按项目分组"（v2 项目层级，2026-07-28 立）— 用户能看清"我在哪些项目上有沉淀"，但**看不清"最近干了啥"**。

v0.4.2 跨项目 CV 视图已经实现"按时间倒序"的能力，但**只是 /cv 页面专用**。/achievements 也应该有这个能力。

v0.4.1 = /achievements 加 view mode toggle，让两种视图同页可切。

## 决策

### 1. 视图模式

| 模式 | 适合 | 数据形态 |
|---|---|---|
| **按项目** (默认) | "我在哪些项目上有沉淀" | 项目分组卡片 + ready/pending/needs_data 计数 |
| **按时间** | "最近干了啥" / "全量时间线" | 所有成就按 date desc 拉平 |

### 2. localStorage 持久化

跟 `cockpit_achievements_collapsed_projects`（项目折叠状态）同模式 — 用户的视图偏好跨 session 保留。

key: `cockpit_achievements_view_mode`

### 3. UI 位置：顶部，跟状态过滤同一行

两列布局：左 = 视图模式 toggle，右 = 状态过滤。
紧凑（mb-4，跟统计卡片紧邻）。

### 4. Timeline 视图复用 AchievementCard 组件

跟 /cv 视图风格一致（项目 emoji + 标题 + 日期 + cv + tags），不重新设计。

支持 inline edit cv 文本（点 Edit2 按钮）+ undo 沉淀。
