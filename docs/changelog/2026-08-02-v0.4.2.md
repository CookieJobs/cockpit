# 2026-08-02 — v0.4.2 跨项目 CV 视图（"一次沉淀多次输出"的输出端基础）

## 状态
**现行版本**（v0.4.2，立）

## 背景

v0.3 沉淀智能化（v0.3.1 / v0.3.3）已经让"沉淀"这一段扎实了，下一步该看"输出"。

v0.4.2 是 v0.4 阶段的核心增量——"跨项目 CV 视图"：
- 用户从成就库（按项目分组）切到"我所有 ready 成就拉成一份简历"
- 直接兑现 GOAL.md 主目标的"一次沉淀, 多次输出"哲学
- 是 v0.7 统一输出引擎（多模板 + LLM 润色）的基础

## 决策

**页面位置**：`/cv`（不是 `/achievements/cv`）—— 它是跟 `/achievements` / `/report` / `/pr` **并列**的视图，不从属于成就库。

**不调 LLM**：v0.4.2 是"结构化展示 + 导出"，LLM 润色留给 v0.7。

**模板系统**：`web/lib/cv-template.ts`（跟 `web/lib/templates.ts` 同模式），导出 3 个纯函数：
- `rangeToSince(preset)` — "1y/2y/3y/all" → since 字符串
- `filterByRange(items, preset)` — 范围过滤
- `generateCvMarkdown(items)` — 生成可贴简历的 markdown（按项目分组 + 项目内按日期 desc）

## UI 设计

**双栏布局**：
- 左：成就列表（按时间倒序，每条含项目 emoji + 标题 + 日期 + cv 文本 + tags）
- 右：实时 markdown 预览

**顶部操作**：
- 范围预设（近 1/2/3 年 / 全部）
- 搜索框（匹配 title / project / cv 文本）
- 复制 / 下载按钮（直接用 markdown）

**主 nav 入口**：`MainBoard` 顶部加 "📄 CV 视图" 链接，跟"写周报 / PR 描述 / 成就"并列。
