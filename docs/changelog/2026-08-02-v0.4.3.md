# 2026-08-02 — v0.4.3 主题切换 bug 修复（Tailwind 字符串被解析成 dark 值）

## 状态
**现行版本**（v0.4.3，立）

## 背景

用户原话: "现在切换模式整个页面没有变化"。

v0.4.2 的 /cv 视图已发完，v0.4.1 时间线 toggle 也上线了。但 v0.4.1 那个版本
introduced 一个**自 v0.3 主题架构落地就潜伏的 bug** — Tailwind 3 把 config 里
的 `rgb(var(--color-X) / <alpha-value>)` 字符串**当作颜色解析了**，把 `var(--color-bg)`
fallback 到 .dark 里的值（10 10 10）写死到编译产物。结果所有 `bg-bg` / `text-fg` /
`border-border` / `bg-accent` 等 utility class 都被**硬编码成 dark 色** ——
切 html class 也没用，CSS 变量级联根本走不到组件层（因为组件没引用 var()，
直接拿 RGB 字面量）。

为啥用户 v0.4.1 才反映？因为 v0.3 默认 dark，硬编码 dark 跟期望一致，肉眼无感。
v0.4.1 后用户试了 light 才发现切不动。

## 调查 + 根因

### 现象

- 点 ThemeToggle → 按钮文字翻（React state 切到 light）
- 但页面视觉**永远是 dark**（body bg 永远是 #0a0a0a，text 永远是 #e5e5e5）
- 切 localStorage 清掉重 load，html 拿到 .light class，也**没用**

### 定位路径

1. **排除 1: React state 切不动？** — 否，按钮文字从「切换到白天模式」变成
   「切换到黑夜模式」，`data-theme-state` 切了，`useTheme()` 返回的 theme
   切了 → state 层 OK。

2. **排除 2: 早期同步脚本坏？** — 否，脚本读 localStorage、设 html class 的逻辑
   看着对，重 load 后 dev tool 也能看到 html.classList 里加了 .light。

3. **排除 3: 浏览器 cache？** — 用 `?cache_bust=1` 硬重载，CSS 文件 v= 变了，
   仍然 dark。

4. **关键诊断: 编译后的 CSS 是不是真用了 var()** ——
   ```bash
   curl -s http://localhost:3002/_next/static/css/app/layout.css | grep -A2 "^\.bg-bg \{"
   ```
   看到：
   ```css
   .bg-bg {
     --tw-bg-opacity: 1;
     background-color: rgb(10 10 10 / var(--tw-bg-opacity, 1));
   }
   ```
   **10 10 10 是字面量**！不是 `rgb(var(--color-bg) / ...)`！

5. **结论: Tailwind 把 `rgb(var(--color-bg) / <alpha-value>)` 当颜色字符串
   解析了**，`var(--color-bg)` 被它 fallback 到当前 CSS 上下文里的值（dark
   模式 .dark 块里 `--color-bg: 10 10 10` 当时生效），写死到产物。

### 为什么 Tailwind 这么干

Tailwind 3 看到 colors 配置里的字符串，会做 **color extraction**。当字符串像
RGB 形式（`rgb(...)`），它尝试提取 RGB 组件，提取不到就**用当前作用域里
同名 CSS 变量的值**当 fallback。

我们的写法 `rgb(var(--color-bg) / <alpha-value>)` 是 Tailwind 3 官方推荐
"用 CSS 变量 + 支持 alpha 变体" 的标准姿势——但**仅当用函数形式时才不会被
解析**。字符串形式 + `<alpha-value>` 占位符 → Tailwind 走 color parser，
碰到 `var(--color-bg)` 就 fallback。

## 决策

**改用函数形式（function form）**——这是 Tailwind 3 文档明确说"不会被颜色
解析器碰"的写法：

```ts
// 之前 (string) - 被解析
bg: { DEFAULT: "rgb(var(--color-bg) / <alpha-value>)" }

// 之后 (function) - 不被解析
bg: {
  DEFAULT: ({ opacityValue }: { opacityValue: number | undefined }) =>
    opacityValue !== undefined
      ? `rgb(var(--color-bg) / ${opacityValue})`
      : "rgb(var(--color-bg))",
}
```

函数形态:
- `opacityValue === undefined` (没写 `bg-bg/15`) → 输出 `rgb(var(--color-bg))`
- `opacityValue === 0.5` (写了 `bg-bg/50`) → 输出 `rgb(var(--color-bg) / 0.5)`

alpha 变体 + CSS 变量都正确。
