# 2026-08-02 — v0.4.5 ChatWindow 默认折叠 (新用户清爽主页)

## 状态
**现行版本**（v0.4.5，立）

## 背景

投资人 Round 2 挑刺 #1: **"ChatWindow 默认展开, 占主页 1/3 屏, 用户进 cockpit
不想聊 AI 只想看自己的项目"**。

v0.2 上线时 chat 默认展开 (true) — 那时候产品定位偏 "AI 聊天驱动的工作流",
AI 窗口是核心入口。但 v0.3 → v0.4 后产品定位变成 "沉淀成就 → 生成履历",
AI 聊天变成 secondary 入口, 主页应该是 "项目 + 成就" 视图, chat 按需展开。

## 决策

**新用户默认折叠, 老用户保留选择** — 跟 lesson #11/#13 同源 "不要视觉堆叠"
原则一致。

行为:
- 新用户 (localStorage 没 `cockpit_chat_collapsed` 标记) → useState 初值 false (折叠)
- 老用户 (localStorage 存了 "0" 展开 / "1" 折叠) → 保留他们的选择
- 切换栏后立即写 localStorage (旧逻辑)
- 视觉效果: 主页变成 "项目 + 成就 spotlight" 清爽视图, 右栏窄条 "展开对话" 入口

## 改动

| 文件 | 改动 |
|---|---|
| [`web/components/MainBoard.tsx`](../../web/components/MainBoard.tsx) | ✏️ `useState<boolean>(true)` → `useState<boolean>(false)` + useEffect 同时识别 "0" 和 "1" |
