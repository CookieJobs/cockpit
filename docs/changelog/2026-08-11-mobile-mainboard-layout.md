# 2026-08-11 — MainBoard 移动端单视图切换

> 状态：现行 · 关联 lessons：#30、#27

## 变更

主页在窄屏下不再把项目看板和对话栏并排压缩：

- 默认显示项目/成就看板，并把对话入口改为右下角悬浮按钮。
- 点击入口后，对话变为全屏工作区；点击「收起」回到原来的看板。
- 桌面端维持原行为：对话是 35% 宽度的右侧栏。
- 顶栏导航改为横向可滚动且不换行，避免中文菜单被挤成逐字竖排。
- 空任务状态的 CTA 从「去对话建项目」改为「去对话添加任务」，并移除「右栏」这类位置依赖文案。

## 决策

| 方案 | 结论 | 原因 |
|---|---|---|
| 窄屏继续并排 | 不采用 | 390px 时对话最小宽度 360px，会把看板挤出视口，核心路径中断。 |
| 窄屏隐藏对话 | 不采用 | 对话仍是创建项目、任务和完成沉淀的重要入口；隐藏会增加冷启动摩擦。 |
| 窄屏全屏对话 + 可回看板 | 采用 | 一个时刻只服务一个明确任务，阅读与输入有足够宽度，且不牺牲看板作为默认主视图。 |

## 防回归

- `web/components/MainBoard.tsx` 保留移动端覆盖层 / 桌面侧栏的完整静态 class，确保
  Tailwind 开发期热更新能从实际消费者立即生成两端规则。
- `web/scripts/test-board-layout.mjs` 编译只扫描 `MainBoard` 的 Tailwind 产物，验证手机
  `fixed` 与桌面 `md:static` / `md:flex-col` 同时存在。

## 验证

- 390×844：看板默认完整可见；展开后对话覆盖整个视口；收起后可回看板。
- 桌面 1280px：对话仍为右侧 448px 面板，不影响项目区。
