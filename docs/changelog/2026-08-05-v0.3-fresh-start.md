## ⚠️ v0.3 真实问题 (不修, 记录)

### 1. 主题切换视觉不变化 (CSS bug)

**症状**: 切到 light 模式, 背景仍 dark。

**根因**: v0.3 tailwind.config.ts 用 `rgb(var(--color-X) / <alpha-value>)` **字符串形式**。
Tailwind 3 看到字符串会走 color parser, 把 `var(--color-bg)` fallback 到当前作用域值
(.dark 块里 `--color-bg: 10 10 10`), 写死到编译产物:

```css
.bg-bg { background-color: rgb(var(--color-bg) / var(--tw-bg-opacity, 1)); }
   ↓ 编译 ↓
.bg-bg { background-color: rgb(10 10 10 / var(--tw-bg-opacity, 1)); }  /* dark 字面量写死 */
```

**lesson #27 修法**: 改 tailwind.config.ts 用函数形式, 让 Tailwind 跳过 color parser 原样输出 `var()`。
v0.3 状态**没有这个修法**。

**发现时机**: 2026-08-05 23:30 主题切换测试
**优先级**: 高 (lesson #27 修法 1-2h)
**新一轮候选**: v0.3.1 立 lesson #27 (Tailwind 函数形式) + 加 1 条不变量测试

### 2. Nav 文字换行 (v0.3 三个 /cv 系列入口挤)

**症状**: 主页 nav "写周报" / "PR 描述" / "CV 视图" 三个链接文字换行 (每行 2-3 字)。

**根因**: v0.3 还没立 Round 7 减法 #1 (合并 nav, 砍 /report + "CV 视图")。
