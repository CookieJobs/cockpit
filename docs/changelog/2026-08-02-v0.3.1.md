# 2026-08-02 — v0.3.1 主动建议机制（outcome 停笔 1.5s 后 AI 自动给 cv 建议）

## 状态
**现行版本**（v0.3.1，立）

## 背景

v0.2 已经有"✨ 润色"按钮 + 任务分类引导 + AI 主动追问。但有一个**漏网**：

> outcome 写完后，用户经常**忘记点润色**。cv 就停在 `完成「${title}」` 兜底，沉淀质量肉眼可见低。

→ v0.3.1 把"主动"从"润色时被追问"扩展到"outcome 写完就建议"。

## 决策

| 维度 | 选 | 不选 |
|---|---|---|
| 触发时机 | debounce 1.5s | 实时（每打一字都调） |
| 触发阈值 | outcome ≥ 30 字 | 任意长度 |
| 建议形式 | ghost 预览 + 采纳/忽略 | 直接替换 cv |
| 跟手动润色 | 互斥（手动润色时关掉建议） | 并存 |
| 失败处理 | 静默（手动润色有 toast） | 弹错误 |

## 改动

- [`web/components/CompleteTaskModal.tsx`](../../web/components/CompleteTaskModal.tsx)：
  - 加 `autoSuggestedCv / autoPolishing / suggestionDismissed` 三个 state
  - 加 debounce useEffect（1.5s 后自动调 polishCv）
  - 在 CV 框上方插入建议区 UI（采纳 / 忽略 按钮）
  - 协调原 `polish()` 函数：手动润色时清空自动建议 + dismiss
